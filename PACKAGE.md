# Phoenixml.Platform

The shared foundation library for the Phoenixml family of XML-aware tools (Editor, Workbench, Studio). Document model, command-based undo/redo, editor primitives, account/license/update plumbing.

```csharp
using Phoenixml.Platform.Abstractions.Documents;
using Phoenixml.Platform.Documents;

public sealed class MyDocument : Document { ... }
```
