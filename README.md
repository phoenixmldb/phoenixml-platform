# Phoenixml.Platform

The shared foundation library for the [Phoenixml](https://phoenixml.dev) family — document model, undo/redo, editor primitives, account/license/update plumbing, and shell scaffolding.

Apache-2.0. See [LICENSE](LICENSE) and [NOTICE](NOTICE).

This is the **foundation library** consumed by Phoenixml.Editor, Phoenixml.Workbench, and future family apps. Vocabulary-specific bindings (XML/XSD, XSLT, XQuery) live in separate packages.
